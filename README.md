# VEOcc++ Project Page

Official project page for:

**VEOcc++: Learning Persistent Voxel Feature Maps for Embodied Online Semantic Occupancy Mapping and Offline Refinement**

Ruoyu Wang, Jiahan Li, Yong Liu, and Kexin Zhang

APRIL Lab, Institute of Cyber-Systems and Control, Zhejiang University

- Project page: https://wryzju.github.io/VEOccpp/
- Paper: https://arxiv.org/abs/2610.27704
- PDF: https://arxiv.org/pdf/2610.27704v1

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
